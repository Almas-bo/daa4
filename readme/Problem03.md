### Problem 3 - Min Cost Climbing Stairs

1. **Задача:** Найти минимальную цену подъёма на верх лестницы, можно шагать на 1 или 2 ступени.
2. **Состояние:** dp[i] — минимальная цена, чтобы оказаться на ступени i.
3. **Переход:** dp[i] = min(dp[i-1] + cost[i-1], dp[i-2] + cost[i-2]).
4. **База:** dp[0] = dp[1] = 0, так как начать можно с любой из первых двух.
5. **Сложность:** Ответ dp[n]. Время O(n), память O(n).
