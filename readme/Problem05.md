### Problem 5 - Longest Common Subsequence

1. **Задача:** Найти длину наибольшей общей подпоследовательности двух строк.
2. **Состояние:** dp[i][j] — LCS первых i символов text1 и первых j символов text2.
3. **Переход:** Символы равны: dp[i-1][j-1] + 1, иначе max(dp[i-1][j], dp[i][j-1]).
4. **База:** Первая строка и столбец таблицы равны 0.
5. **Сложность:** Время O(m·n), память O(m·n).
