### Problem 10 - House Robber

1. **Задача:** Найти максимальную сумму, которую можно украсть, не грабя два соседних дома.
2. **Состояние:** dp[i] — максимум, который можно получить из первых i домов.
3. **Переход:** dp[i] = max(dp[i-1], dp[i-2] + nums[i]): пропустить дом или ограбить.
4. **База:** Хранятся только два последних значения.
5. **Сложность:** Время O(n), память O(1).
