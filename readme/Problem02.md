### Problem 2 - Jump Game II

1. **Задача:** Найти минимальное число прыжков, чтобы дойти до последнего индекса массива.
2. **Состояние:** dp[i] — минимум прыжков до индекса i.
3. **Переход:** Из i можно прыгнуть в i+j при j от 1 до nums[i]: dp[i+j] = min(dp[i+j], dp[i]+1).
4. **База:** dp[0] = 0, остальные изначально равны бесконечности.
5. **Сложность:** Время O(n²), память O(n).
