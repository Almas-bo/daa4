### Problem 8 - Palindromic Substrings

1. **Задача:** Посчитать количество палиндромных подстрок строки.
2. **Состояние:** dp[i][j] = true, если подстрока s[i..j] — палиндром.
3. **Переход:** Палиндром, если s[i] == s[j] и (длина не больше 3 или dp[i+1][j-1]).
4. **База:** Подстроки длины 1 и 2 проверяются напрямую по символам.
5. **Сложность:** Счётчик растёт при каждом true. Время O(n²), память O(n²).
