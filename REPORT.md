### DAA Assignment4 - Report and Defense

##### Problem 1 - Counting Bits

1. **Задача:** Для каждого числа от 0 до n нужно посчитать количество единиц в двоичной записи.
2. **Состояние:** dp[i] — число единиц в i.
3. **Переход:** dp[i] = dp[i >> 1] + (i & 1): число без последнего бита плюс сам последний бит.
4. **База:** dp[0] = 0, остальные считаются слева направо.
5. **Сложность:** Время O(n), память O(n).

##### Problem 2 - Jump Game II

1. **Задача:** Найти минимальное число прыжков, чтобы дойти до последнего индекса массива.
2. **Состояние:** dp[i] — минимум прыжков до индекса i.
3. **Переход:** Из i можно прыгнуть в i+j при j от 1 до nums[i]: dp[i+j] = min(dp[i+j], dp[i]+1).
4. **База:** dp[0] = 0, остальные изначально равны бесконечности.
5. **Сложность:** Время O(n²), память O(n).

##### Problem 3 - Min Cost Climbing Stairs

1. **Задача:** Найти минимальную цену подъёма на верх лестницы, можно шагать на 1 или 2 ступени.
2. **Состояние:** dp[i] — минимальная цена, чтобы оказаться на ступени i.
3. **Переход:** dp[i] = min(dp[i-1] + cost[i-1], dp[i-2] + cost[i-2]).
4. **База:** dp[0] = dp[1] = 0, так как начать можно с любой из первых двух.
5. **Сложность:** Ответ dp[n]. Время O(n), память O(n).

##### Problem 4 - Longest Increasing Subsequence

1. **Задача:** Найти длину самой длинной строго возрастающей подпоследовательности.
2. **Состояние:** dp[i] — длина LIS, заканчивающейся в элементе i.
3. **Переход:** Для каждого j < i с nums[j] < nums[i]: dp[i] = max(dp[i], dp[j] + 1).
4. **База:** Изначально dp[i] = 1.
5. **Сложность:** Ответ — максимум dp. Время O(n²), память O(n).

##### Problem 5 - Longest Common Subsequence

1. **Задача:** Найти длину наибольшей общей подпоследовательности двух строк.
2. **Состояние:** dp[i][j] — LCS первых i символов text1 и первых j символов text2.
3. **Переход:** Символы равны: dp[i-1][j-1] + 1, иначе max(dp[i-1][j], dp[i][j-1]).
4. **База:** Первая строка и столбец таблицы равны 0.
5. **Сложность:** Время O(m·n), память O(m·n).

##### Problem 6 - Edit Distance

1. **Задача:** Найти минимальное число вставок, удалений и замен, чтобы превратить word1 в word2.
2. **Состояние:** dp[i][j] — расстояние между первыми i символами word1 и первыми j символами word2.
3. **Переход:** Символы равны: dp[i-1][j-1], иначе 1 + min(замена, удаление, вставка).
4. **База:** dp[i][0] = i и dp[0][j] = j.
5. **Сложность:** Время O(m·n), память O(m·n).

##### Problem 7 - Longest Palindromic Subsequence

1. **Задача:** Найти длину самой длинной палиндромной подпоследовательности строки.
2. **Состояние:** dp[i][j] — длина такой подпоследовательности в подстроке s[i..j].
3. **Переход:** Символы s[i] и s[j] равны: dp[i+1][j-1] + 2, иначе max(dp[i+1][j], dp[i][j-1]).
4. **База:** dp[i][i] = 1, i идёт справа налево.
5. **Сложность:** Время O(n²), память O(n²).

##### Problem 8 - Palindromic Substrings

1. **Задача:** Посчитать количество палиндромных подстрок строки.
2. **Состояние:** dp[i][j] = true, если подстрока s[i..j] — палиндром.
3. **Переход:** Палиндром, если s[i] == s[j] и (длина не больше 3 или dp[i+1][j-1]).
4. **База:** Подстроки длины 1 и 2 проверяются напрямую по символам.
5. **Сложность:** Счётчик растёт при каждом true. Время O(n²), память O(n²).

##### Problem 9 - Maximum Subarray

1. **Задача:** Найти наибольшую сумму непрерывного подмассива.
2. **Состояние:** cur — лучшая сумма подмассива, заканчивающегося в текущем элементе.
3. **Переход:** cur = max(nums[i], cur + nums[i]): продолжить подмассив или начать заново.
4. **База:** Начальное значение — nums[0].
5. **Сложность:** Ответ — максимум cur (алгоритм Кадане). Время O(n), память O(1).

##### Problem 10 - House Robber

1. **Задача:** Найти максимальную сумму, которую можно украсть, не грабя два соседних дома.
2. **Состояние:** dp[i] — максимум, который можно получить из первых i домов.
3. **Переход:** dp[i] = max(dp[i-1], dp[i-2] + nums[i]): пропустить дом или ограбить.
4. **База:** Хранятся только два последних значения.
5. **Сложность:** Время O(n), память O(1).
